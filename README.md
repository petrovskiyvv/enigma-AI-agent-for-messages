# ENIGMA HACK: AI-агент технической поддержки «ЭРИС»

Решение для хакатона ENIGMA HACK от компании «ЭРИС». Система автоматизирует обработку входящих писем в службу технической поддержки: извлекает ключевые данные, классифицирует обращения по категориям, определяет тональность и генерирует черновик ответа на основе базы знаний.

---

## Цели проекта

1. **Автоматизация обработки писем** — сокращение времени реакции на обращения клиентов
2. **Структурирование данных** — веб-таблица с возможностью выгрузки в CSV
3. **Анализ тональности** — определение эмоционального окраса письма (позитив / Нейтральноно / негатив)
4. **Генерация ответов** — шаблонные ответы на основе категории обращения с возможностью ручного редактирования

### Пользовательский путь

1. Оператор открывает веб-приложение и видит таблицу обращений
2. Переходит во вкладку **«Анализ письма»** и вставляет текст входящего письма
3. AI-агент автоматически извлекает ФИО, контакты, заводские номера приборов, определяет тональность и категорию, генерирует черновик ответа — и создаёт тикет
4. Оператор открывает тикет в таблице, проверяет черновик, при необходимости редактирует и сохраняет
5. Система сохраняет итоговый ответ и меняет статус тикета

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/health` | Проверка работоспособности |
| `GET` | `/api/tickets` | Список тикетов. Параметры: `status`, `tone`, `category`, `search` |
| `GET` | `/api/tickets/{id}` | Один тикет по ID |
| `POST` | `/api/tickets` | Создать тикет вручную |
| `PATCH` | `/api/tickets/{id}` | Обновить поля тикета (статус, ответ) |
| `POST` | `/api/analyze` | Принять текст письма, извлечь данные, создать тикет |
| `GET` | `/api/stats` | Статистика по тональности, категориям, статусам |
| `GET` | `/api/export/csv` | Выгрузить все тикеты в CSV (UTF-8 с BOM) |

Интерактивная документация (Swagger UI): `http://localhost:8000/docs`

## Что извлекает AI-агент

При вызове `POST /api/analyze` класс `TextAnalyzer` выполняет:

- **Тональность** — rule-based по ключевым словам (заготовка под замену на BERT/RoBERTa)
- **Категория** — Неисправность / Калибровка / Документация / Общий вопрос
- **ФИО** — regex по подписи («С уважением, …»)
- **Email** — regex
- **Телефон** — regex (форматы +7 / 8)
- **Заводские номера** — набор regex-паттернов для разных форматов (числовые, буквенно-цифровые)
- **Краткое резюме** — первое предложение письма
- **Черновик ответа** — шаблон по категории

Логика изолирована в `services/analyzer.py` и не зависит от слоя API — на хакатоне заменяется на ML-модель без изменений в роутерах.

## Запуск

### Вариант A: через Docker (рекомендуется)

```bash
cd project/
docker compose up --build
```

Бэкенд: `http://localhost:8000` · PostgreSQL: `localhost:5432`

### Вариант B: локально без Docker

```bash
cd project/backend/
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Фронтенд (в отдельном терминале)

```bash
cd project/frontend/

# Выполнить один раз для инициализации Flutter-проекта:
flutter create . --project-name enigma_support
flutter pub add http
flutter config --enable-web

# Запуск:
flutter run -d chrome
```

> При изменении файлов после запуска используйте `flutter clean && flutter pub get && flutter run -d chrome` для полной пересборки.

## Анализ рисков

| Риск | Вероятность | План минимизации |
|---|---|---|
| Низкая точность извлечения заводских номеров из неструктурированного текста | Высокая | Ручная корректировка всех полей оператором в диалоге тикета до сохранения |
| Сложности интеграции ML-моделей с бэкендом в условиях ограниченного времени | Средняя | `TextAnalyzer` изолирован в одном классе — заменяется без изменения API |
| Блокировка почтового ящика при IMAP-опросе в процессе тестирования | Средняя | Разработка и демонстрация работает на mock-данных; IMAP подключается на финальном этапе |
| Нехватка времени на построение полноценного RAG | Высокая | Шаблонные ответы как рабочий fallback; RAG добавляется поверх при наличии времени |

## Планируемые улучшения на хакатоне

- Подключение IMAP/SMTP для автоматического получения и отправки писем
- Замена `TextAnalyzer` на модели Hugging Face (ruBERT для тональности, NER для извлечения сущностей)
- RAG на базе руководств по эксплуатации газоанализаторов и FAQ
- Подключение реального PostgreSQL вместо in-memory store
- Уведомления в Telegram при поступлении новых обращений
- Экспорт в XLSX дополнительно к CSV
